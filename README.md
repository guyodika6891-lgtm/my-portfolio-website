# 🌟 Guyo Dika — Personal Portfolio

A modern, animated portfolio website showcasing my work as a Lecturer and Technology Innovator at Werabe University.

## ✨ Features

- 🎨 **Modern gradient design** with smooth animations
- 📱 **Fully responsive** — works on mobile, tablet, and desktop
- 💎 **Glassmorphism navbar** with backdrop blur
- ✨ **Micro-interactions** on every hover
- 🌈 **Animated gradients** throughout
- 🎯 **Smooth scroll** navigation
- ⚡ **Fast loading** — pure HTML/CSS/JS
